# Finars Studio 1.0

Modern, Apple-inspired website for **FIN ARS d.o.o.** — architectural studio from Zagorje ob Savi, Slovenia.

## Features
- Clean, sophisticated design (desktop + mobile)
- Project gallery with lightbox zoom
- Animated hero background
- Pages: Home, Projects, About, Services, Contact

## Live site (after enabling GitHub Pages)
**https://tommyvimeo-gif.github.io/Finars-Studio-1.0/**

## How to enable GitHub Pages
1. Go to Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / root
4. Save

## Local use
Open `index.html` in a browser.

## Images
Add project images into the `images/` folder (from the original finars.si or the provided zip).
